# Fiche de synthèse — Chapitre 3 : La méiose

## 1. [[La méiose dans le cycle reproductif]]
La **méiose** permet de passer d'une cellule diploïde (2n) à 4 gamètes haploïdes (n).

## 2. Le brassage interchromosomique
Un individu à n paires de chromosomes peut produire $2^n$ gamètes différents.
